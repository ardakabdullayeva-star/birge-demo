# Бірге · демонстрация для семинара

Прототип показывает работу с вымышленным учеником ДЕМО-01: наблюдения сотрудников, отметку о согласии, проект внутреннего протокола и утверждаемую руководителем консилиума PDF-сводку для родителей.

## Запуск

1. Установите Python 3.12 и выполните `pip install -r requirements.txt`.
2. Запустите `streamlit run app.py`.
3. В боковой панели переключайте роли. Для демонстрации доступен вымышленный ученик; три записи уже заполнены.
4. В кабинете руководителя консилиума укажите ФИО, утвердите сводку и скачайте PDF.

В демоверсии нет настоящей авторизации, ИИ и надёжного постоянного хранилища. SQLite-файл создаётся автоматически и может исчезнуть при перезапуске облачного сервера. Не вводите данные реальных детей. Для реального внедрения нужны контроль доступа, проверенное хранение, правила согласия и отправки документов, журнал действий и профессиональная проверка протокола. Название выступления не означает, что сайт ставит диагноз.
